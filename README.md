# Google Maps 生活道路(道幅5.5m未満)チェッカー

**Google Maps 生活道路チェッカー** は、2026年9月1日に施行される改正道路交通法（生活道路における法定最高速度の引き下げ）に対応し、Googleマップ上で道路の幅員や中央線の有無を判定して警告・表示するGoogle Chrome拡張機能です。

走行ルートの事前確認や、日常の安全運転計画・ハザード確認にご活用いただけます。

---

## 【重要】免責事項およびご利用上の注意

本拡張機能をご利用いただくにあたり、以下の事項を必ずご確認ください。

> [!CAUTION]
> ### 1. 速度超過を誘発する目的ではありません
> 本ツールは、2026年9月以降に法定速度が30km/hへ引き下げられる生活道路を事前に確認し、**危険箇所の把握や安全運転意識の向上を支援すること** を目的としています。
> **「60km/hで走れる道路を探して速度を出す」といった速度超過や危険運転を助長・誘発する目的では絶対に使用しないでください。**

> [!IMPORTANT]
> ### 2. 現地の道路標識・道路標示が最優先です
> 法定速度（60km/h / 30km/h）は、**「最高速度を指定する標識や路面標示がない道路」にのみ適用**されます。
> 現場に速度指定標識や道路標示がある場合は、**本ツールの判定結果に関わらず現地の標識が最優先**で適用されます。実際の運転時は必ず現地の道路標識・交通規制に従ってください。

> [!WARNING]
> ### 3. 誤検知の可能性について
> 本ツールは公開地図データ（OpenStreetMap）をもとに道路情報を判定しています。そのため、以下のケース等で実際の道路状況と異なる判定となる場合があります：
> 
> - **橋や立体交差の周辺**: 橋や高架道路の下・近隣に農道や管理道路が近接している場合、周囲の小道を誤って拾ってしまうことがあります。
> - **地図データの未登録・新設道路**: 幅員や車線情報が未登録の道路では推定による判定となります。
> - **私道・農道等**: 公道・私道の判別が難しい区間では、安全側に倒して「30km/h 制限対象」と判定されます。

## 2026年9月1日施行 改正道路交通法の概要

2026年9月1日施行の改正道路交通法施行令により、歩行者や自転車の安全を確保するため、生活道路における法定速度が従来の60km/hから **「30km/h」** へ引き下げられます。

### 対象となる道路（すべて満たす道路）
1. **一般道路** であること
2. **最高速度を指定する標識や路面標示がない** こと
3. **中央線（センターライン）や中央分離帯が設けられていない** こと（主に道幅5.5m未満の道路）

| 道路の区分 | 改正前（〜2026年8月31日） | 改正後（2026年9月1日〜） |
|---|---|---|
| **中央線のある一般道**（標識なし） | 60km/h | **60km/h**（変更なし） |
| **中央線のない生活道路**（標識なし） | 60km/h | 🚨 **30km/h**（新基準） |
| **規制標識のある道路** | 標識の指定速度 | **標識の指定速度**（最優先） |

## 判定結果の見方

| 表示 | 判定内容 | 説明 |
|---|---|---|
| **30km/h 制限対象** | 生活道路 / 道幅5.5m未満 / 農道 | 中央線がなく、2026年9月以降に法定速度30km/hの対象となる道路です。 |
| **通常道路** | 幹線道路 / 道幅5.5m以上 / 中央線あり | 国道・主要県道や中央線のある2車線道路です。（標識指定速度または法定速度） |

## 道幅データの取得と推定判定方法について

### 1. 実測幅員データ（`width`）がある場合
OpenStreetMap上に正確な道幅（例：`width=4.0` $\to$ 4.0m）が登録されている道路では、その数値を直接読み取って「5.5m未満か」を判定します。

### 2. 明示的な道幅データがない場合
日本国内のすべての道路に実測の道幅（m）が登録されているわけではありません。そのため、幅員データが未記載の区間では以下の**道路属性データを組み合わせて論理的な推定判定**を行っています：

- **道路の種別（`highway` タグ）**:
  - `residential`（住宅街路）、`track`（農道・あぜ道）、`service`（路地・敷地内通路）など。
  - 日本の住宅街や農道は、道路構造令の基準上、そのほとんどが「中央線がなく道幅5.5m未満」であるため、生活道路（30km/h制限対象）として判定しています。
- **車線数（`lanes` タグ）**:
  - `lanes=1`（1車線）または車線情報なしの小道を狭路（中央線なし）として特定します。
- **主要路線・橋梁（`ref`, `bridge`, 道路名）**:
  - 国道・主要県道（`primary`, `secondary`, `tertiary`）や長大橋梁は、最低でも5.5m以上（2車線＋中央線）確保されているため、通常道路として判定します。

> [!NOTE]
> 本ツールの判定は地図データに基づく推定を含みます。実際の走行時は必ず現地の道路標識・センターラインの有無を目視でご確認ください。

## インストール方法

1. 本リポジトリのファイル一式（`narrow-road-checker` フォルダ）を用意します。
2. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して開きます。
3. 画面右上にある **「デベロッパー モード」** のスイッチを **ON** にします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. ダウンロードした `narrow-road-checker` フォルダを選択します。
6. 拡張機能一覧に本ツールが追加され、利用可能になります。

---

## 使い方

1. [Googleマップ](https://www.google.com/maps) または `google.co.jp/maps` を開きます。
2. 地図上またはストリートビュー画面の右上に **「生活道路チェッカー」** パネルが表示されます。
3. 以下のいずれかの操作で判定を実行できます：
   - **ボタン**: パネル内の **「現在地（画面中心）を判定」** ボタンをクリック（照会中はボタンがグレーアウトします）
   - **キーボード**: キーボードの **`R`** キーを押す
   - **右クリック**: マップ上の調べたい道路を右クリック
4. パネルに判定結果と詳細が表示されます。

---

## アンインストール方法

1. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して開きます。
2. 拡張機能一覧から **「Google Maps 生活道路(道幅5.5m未満)チェッカー」** を探します。
3. カード内にある **「削除」** ボタンをクリックします。
4. 確認ダイアログで **「削除」** をクリックすると、拡張機能が完全にアンインストール（削除）されます。
